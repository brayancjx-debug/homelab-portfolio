# 📊 Zabbix — Monitoreo del Homelab

> **Objetivo:** Monitorear en tiempo real el estado de mis Maquinas Virtuales, servicios de red y disponibilidad, con alertas automáticas ante fallos.

---

## 1. Resumen del proyecto

- Implementacion de la maquina virtual, como host del servicio Zabbix.
- Creacion de grupos para la correcta agrupacion de los servidores (MV).
- Implementación de dashboard personalizado por cada servicio.
